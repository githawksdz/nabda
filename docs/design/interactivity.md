# Interactivity

Updated: 26 September 2026. Buttons and badges follow the type roles in `typography.md`.

## Actions

- One primary action per card. A second path is a text link only when it goes somewhere different.
- Do not make a whole card clickable when it already contains a button or link.
- Button labels are Geist, 14px, weight 600, sentence case. Danger uses the same face and weight, with color and wording.
- Links are Geist, 13–14px, weight 600, with a visible focus state. An arrow means navigation.

## Touch and focus

- Main controls keep a 44px minimum height.
- Focus is a visible ring. Color alone is not the only state.
- Badges are not headlines. An interactive badge still needs a 44px target if it is the control.

## Reading order

For the Pro card: badge, headline, description, action, then the short benefit list. Do not announce the card when it scrolls into view. The action is “Préparer ma garde”.

## Sheets

Auth and personalization use one bottom sheet. The title lives in the sheet. Closing and saving are explicit buttons, not a swipe-only path.
