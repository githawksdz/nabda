# Nabda design rules

Living rules for the doctor-facing product. When a design-system, typography, interaction, UX, or motion decision changes, update the matching file in this folder in the same change. Add a short dated note at the top of that file. Do not open a new phase document for a rule that belongs here.

Historical audits stay in `docs/ui/` and `docs/ux/`. If they disagree with this folder, this folder wins.

| File | What belongs here |
| --- | --- |
| [typography.md](./typography.md) | Families, roles, sizes, and where each face may appear |
| [ux.md](./ux.md) | What the interface promises, placement, and trust |
| [interactivity.md](./interactivity.md) | Controls, focus, touch, and how actions are offered |
| [motion.md](./motion.md) | What may move, for how long, and what stays still |
